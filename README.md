\# 狗子查询系统



一个适用于 AstrBot 的关键词查询与分页菜单插件。



\## 功能



\* 🔍 关键词完全匹配自动回复

\* 📋 独立的菜单数据库

\* 💬 独立的关键词回复数据库

\* 📖 菜单分页显示

\* 🔢 使用 `#数字` 快速切换菜单页面

\* 🔧 管理员可以直接通过 QQ 添加、修改、删除内容

\* ⚙️ 支持独立开启/关闭关键词回复

\* ⚙️ 支持独立开启/关闭菜单功能

\* 💾 数据自动保存，无需修改 Python 代码

\* 🚀 可直接安装到 AstrBot



\## 菜单



菜单每页显示 10 条内容。



发送：



```text

\#1

```



显示第一页：



```text

内容菜单（1/3）



1\. 内容一

2\. 内容二

3\. 内容三

4\. 内容四

5\. 内容五

6\. 内容六

7\. 内容七

8\. 内容八

9\. 内容九

10\. 内容十



请根据以上内容发送关键词以查询问题答案，发送#+数字切换菜单页面

```



发送：



```text

\#2

```



即可查看第二页。



例如：



```text

请根据以上内容发送关键词以查询问题答案，发送#+数字切换菜单页面

```



\## 关键词回复



关键词采用\*\*完全匹配\*\*。



例如管理员添加：



```text

/添加回复 你好 | 你好，我是狗子！

```



用户发送：



```text

你好

```



狗子回复：



```text

你好，我是狗子！

```



但是下面这些不会触发：



```text

你好啊

你好！

你好 狗子

```



也就是说，关键词必须与用户发送的消息\*\*完全一致\*\*。



\## 管理员命令



\### 回复管理



添加回复：



```text

/添加回复 关键词 | 回答

```



例如：



```text

/添加回复 你好 | 你好，我是狗子！

```



修改回复：



```text

/修改回复 关键词 | 新回答

```



例如：



```text

/修改回复 你好 | 您好，我是狗子查询系统。

```



删除回复：



```text

/删除回复 关键词

```



例如：



```text

/删除回复 你好

```



查看全部回复：



```text

/查看回复

```



\### 菜单管理



添加菜单：



```text

/添加菜单 内容

```



例如：



```text

/添加菜单 游客须知

```



修改菜单：



```text

/修改菜单 原内容 | 新内容

```



例如：



```text

/修改菜单 游客须知 | 游客入园须知

```



删除菜单：



```text

/删除菜单 内容

```



例如：



```text

/删除菜单 游客入园须知

```



查看全部菜单：



```text

/查看菜单

```



\## 数据存储



插件使用两个完全独立的数据文件。



```text

data/

├── replies.json

└── menu.json

```



\### replies.json



保存关键词和回答：



```json

{

&#x20;   "你好": "你好，我是狗子！",

&#x20;   "你是谁": "我是狗子查询系统。"

}

```



\### menu.json



保存菜单内容：



```json

\[

&#x20;   "游客须知",

&#x20;   "开放时间",

&#x20;   "门票价格",

&#x20;   "交通方式"

]

```



修改菜单不会影响关键词回复。



修改关键词回复也不会影响菜单。



\## 插件配置



插件提供两个独立的功能开关：



```text

是否启用关键词自动回复

是否启用菜单分页

```



\### 关键词回复开关



关闭后：



```text

用户 → 关键词

```



不会触发自动回复。



\### 菜单开关



关闭后：



```text

用户 → #1

```



不会显示菜单。



两个功能互不影响。

\## 安装



将整个：



```text

astrbot\_plugin\_gouzi\_query

```



文件夹打包成 ZIP。



然后在 AstrBot WebUI：



```text

插件

→ 安装插件

→ 上传插件

```



选择 ZIP 文件即可。



也可以直接通过 GitHub 仓库安装。



\## 注意事项



管理员命令只有 AstrBot 管理员可以使用。



普通用户只能：



```text

\#1

\#2

\#3

...

```



查看菜单以及发送关键词查询答案。



关键词回复采用严格完全匹配，不进行模糊匹配。
